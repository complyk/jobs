# jobs

Tracked job postings, one entry per posting, written to the format in [TEMPLATE.md](TEMPLATE.md).

Each entry records the title and company, the posting date with the evidence used to establish it (`~` marks an approximate date), the canonical listing URL plus any duplicate listings, a one-line company profile with regulator/licence where known, location (city, free zone, or remote-UAE), engagement type and salary if stated, reporting line if stated, and a condensed 5–8 line summary of the job description covering mandate, responsibilities, regulatory scope, must-have qualifications, experience, and any required licences or approvals (e.g. DFSA Authorised Individual, FSRA Approved Person).
